# Format recipes

| Format | Canvas | Main content limits |
|---|---|---|
| Square | 1080 by 1080 px | About three short headline lines and one supporting sentence |
| Portrait | 1080 by 1350 px | A headline, short explanation and one image or metadata block |
| Story | 1080 by 1920 px | Essential content from y=180 to y=1670; review destination app overlays |
| Landscape | 1200 by 630 px | About two short headline lines and one supporting sentence |
| Presentation | 1280 by 720 px, 16:9 | One main point per slide |
| Documents | A4 and US Letter | Styles control text flow; tables expand as content is added |

These are supplied working canvases, not a claim that every social network requires these sizes. Check the destination's current crop and overlay treatment before posting. Keep meaningful content away from edges. For a long headline, shorten it or use the portrait layout before reducing the type size.

In the external Office kit, all social sources are one-slide editable PPTX files. The preview PNG is rendered at the canvas's exact pixel dimensions. The native Keynote files cover the seven-slide presentation systems; social PPTX files may be opened in either PowerPoint or Keynote.
