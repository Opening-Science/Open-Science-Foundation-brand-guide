# Contributing

Use a focused branch and pull request. Run the two commands in AGENTS.md. Explain source changes, licence classifications and relevant rendering checks. Preserve original logo files and update provenance only from an authorised source.

Submit only work you are entitled to contribute. Contributions to a file are offered under its existing scoped licence, subject to separately identified third-party rights. Do not add a new licence, asset or copyrighted excerpt without recording its provenance and obtaining the necessary rights. Changes to logo permissions, public visibility or design approval need an explicit owner decision. No contributor agreement or assignment of third-party rights is implied by this file.

Open-licensed documentation and code may be adapted for other identities under their licences. OSF-specific visual rules govern work represented as OSF branding; they do not remove those adaptation rights.
